## Projects

- [TranslateKhak](https://adeshkin-translate-khakas.hf.space/)
  - Developed an app that combines dictionary lookup, search through usage examples in a parallel corpus, and text-to-speech for the Khakas language - [code](https://github.com/adeshkin/translate-khakas-hf-space).
- [khakas-mt](https://github.com/adeshkin/khakas-mt)
  - Built reproducible training and evaluation pipelines for Khakas ↔ Russian machine translation, including full fine-tuning of NLLB-200 and LoRA fine-tuning of Hy-MT2.
- [aeronetlib](https://github.com/adeshkin/aeronetlib)
  - Contributed to an open-source toolkit for tiled and streaming processing of large images.
- [Khakas–Russian Parallel Corpus](https://huggingface.co/datasets/adeshkin/khakas-russian-parallel-corpus)
  - Led a **team of 50 translators** to build the corpus, comprising **215k sentence pairs**; this work contributed to the addition of Khakas to Yandex Translate.
- [Khakas Monolingual Corpus](https://huggingface.co/datasets/adeshkin/khakas-monolingual-corpus)
  - Created the first Khakas monolingual corpus, containing **258k sentences**. It was used to add Khakas-language support and autocomplete to Yandex Keyboard.
