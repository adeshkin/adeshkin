## Projects

- Developed 🌐 [TranslateKhak](https://adeshkin-translate-khakas.hf.space/), an app that combines dictionary lookup, search through usage examples in a parallel corpus, and Khakas text-to-speech (💻 [code](https://github.com/adeshkin/translate-khakas-hf-space)).
- Built 🛠️ [khakas-mt](https://github.com/adeshkin/khakas-mt) with reproducible training and evaluation pipelines for Khakas ↔ Russian machine translation, including full fine-tuning of NLLB-200 and LoRA fine-tuning of Hy-MT2.
- Led a **50-person team of translators** to build the 📚 [Khakas–Russian Parallel Corpus](https://huggingface.co/datasets/adeshkin/khakas-russian-parallel-corpus), comprising **159k sentence pairs**; this work contributed to the launch of Khakas in Yandex Translate.
- Created the first 📚 [Khakas Monolingual Corpus](https://huggingface.co/datasets/adeshkin/khakas-monolingual-corpus), containing **258k sentences**. It was used to add Khakas-language support and autocomplete to Yandex Keyboard.
- Contributed to 🛠️ [aeronetlib](https://github.com/adeshkin/aeronetlib), an open-source toolkit for tiled and streaming processing of large images.
